# Changelog

이 프로젝트의 주요 변경 사항은 이 파일에 기록합니다. 형식은 [Keep a Changelog](https://keepachangelog.com/ko/1.0.0/)를 따르며, 버전은 [Semantic Versioning](https://semver.org/lang/ko/)을 따릅니다.

## [1.1.0] - 2026-04-26

### Added

- 연간 보기 **특이사항 카드**에 `Ctrl + D` 복제 및 `Shift + 드래그` 복제 동작 추가.
- 일정 편집 팝업에 **작업자 필드 + 자동완성 추천 검색** 추가 (접두 입력 기반, 키보드/마우스 선택 지원).
- 주간 보기 구성원 헤더에 **`+ 일정추가` 버튼** 추가: 기본값(이번주 월~금, `추가 업무`, 기본 일정 색상, 현재 구성원)으로 즉시 생성 후 편집.
- 주간 보기 일정 카드에 **좌/우 리사이즈 핸들** 및 카드 본문 **드래그 이동(행 고정)** 지원.

### Changed

- 주간 보기 일정 편집 팝업 위치를 뷰포트 내부로 보정해 하단 카드 더블클릭 시에도 잘리지 않도록 개선.
- 주간 보기 리사이즈 UX를 개선해 드래그 중 **실시간 폭/위치 프리뷰**와 **Ghost 아웃라인** 제공.
- 주간 보기 조직/프로젝트 표기를 단순화하여 **드롭다운 이름 그대로** 회색 박스로 표시.
- 주간 보기 `+ 일정추가` 버튼 스타일을 녹색으로 변경.

## [1.0.0] - 2026-04-25

### Added

- 헤더에 **연간 보기** / **주간 보기** 탭: 기존 타임라인은 연간 보기로 유지.
- **주간 보기**: 기준일(오늘) 주차를 기준으로 지난주·이번주·다음주 3열, 구성원별 업무 카드(제목, `M/d ~ M/d` 기간).
- 주간 보기에서 **직군 필터**(기존 `JobTitleFilter`) 및 **이름(구성원) 다중 선택 필터**.
- 주간 열별 배경 구분(회색 / 파랑 / 짙은 파랑) 및 주차를 가로로 넘나는 일정에 **그라데이션 연결** 표현.
- 주간 보기 시 일정이 연말·연초를 넘을 수 있도록 **다중 연도 Firestore 일정 동기화** 병합.
- `scheduleViewMode`, `weekViewMemberIds` 상태를 localStorage에 저장 (`scheduleViewMode`, `weekViewMemberIds` 키).
- 일정 편집 팝업에서 **시작일/종료일 직접 입력 편집** 지원(드래그 조정과 병행 가능).
- 주간 보기 상단 날짜 행에 **공휴일명 소형 표시** 및 공휴일 배경 자동 강조.

### Changed

- `useFirebaseSync`가 일정 동기화에 사용할 연도 배열 `scheduleSyncYears`를 받도록 확장.
- 앱 패키지 버전을 **1.0.0**으로 지정하고 변경 이력을 본 `CHANGELOG.md`에 기록하기 시작함.
- 주간 보기 구성원 내부 카드 정렬을 **프로젝트 우선, 조직 후순**으로 조정.
- 주간 보기 구성원 섹션을 병합 헤더 방식에서 **태그 오버레이 방식(이름/지난주 통계)** 으로 변경해 가독성 개선.
- 주간 보기의 **오늘(파랑) 세로 라인**을 구성원 간 간격 포함 전체 영역에 연속 표시되도록 개선.
- 연간 보기의 오늘(파랑) 세로 라인이 일정 카드보다 위에 표시되도록 레이어 우선순위 조정.
- 주간 보기 이름 필터의 의미를 명확화: `null=전체`, `[]=전체 해제`, `[id...]=선택 표시`로 동작 통일.
