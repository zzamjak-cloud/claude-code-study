AI 기반 게임 기획서 작성 도구

다운로드

🍎 macOS Apple Silicon & Intel 🪟 Windows 64-bit
⚠️ Windows 사용자 안내
SmartScreen 경고가 표시될 수 있습니다. "추가 정보" → "실행"을 클릭하세요.

주요 기능

📝 기획서 작성

Gemini 2.5 Flash를 활용한 체계적인 게임 기획서 작성. 템플릿 기반으로 일관된 품질 유지.

📊 시장 분석

Gemini 2.0 Flash + Google Search Grounding으로 실시간 게임 시장 분석.

📚 Notion 연동

마크다운 기획서를 Notion 페이지로 자동 변환. 테이블 완벽 지원.

🔄 버전 관리

기획서 버전 스냅샷 저장 및 비교. 변경 이력 추적.

설치 가이드

macOS

  1. .dmg 파일을 다운로드합니다.
  2. 다운로드된 파일을 더블클릭하여 엽니다.
  3. Game Planner 아이콘을 Applications 폴더로 드래그합니다.
  4. 처음 실행 시 "확인되지 않은 개발자" 경고가 표시되면:
    • 시스템 설정 → 개인정보 보호 및 보안으로 이동
    • "확인 없이 열기" 클릭

Windows

  1. .exe 또는 .msi 파일을 다운로드합니다.
  2. 다운로드된 설치 파일을 실행합니다.
  3. SmartScreen 경고가 표시되면:
    • "추가 정보" 클릭
    • "실행" 클릭
  4. 설치 마법사의 안내에 따라 설치를 완료합니다.

시작하기

  1. Gemini API Key 발급

    Google AI Studio 에서 무료로 API Key를 발급받습니다.

  2. 앱 설정

    앱 실행 후 설정(⚙️)에서 API Key를 입력합니다.

  3. 기획서 작성 시작

    새 세션을 만들고 게임 아이디어를 입력하면 AI가 기획서를 작성합니다.
