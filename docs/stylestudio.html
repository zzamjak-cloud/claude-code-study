주요 기능

🔍 이미지 분석

Gemini 2.5 Flash를 활용한 이미지 스타일, 캐릭터, 구도 분석. 상세 프롬프트 추출.

✨ 이미지 생성

Gemini 3 Pro Image로 분석 결과 기반 이미지 생성. Grid 레이아웃 지원.

🎭 9가지 세션 타입

스타일, 캐릭터, 배경, 아이콘, UI, 로고, 픽셀아트(캐릭터/배경/아이콘) 지원.

📁 폴더 관리

무제한 깊이의 폴더 구조로 세션 정리. 드래그앤드롭 지원.

설치 가이드

macOS

  1. .dmg 파일을 다운로드합니다.
  2. 다운로드된 파일을 더블클릭하여 엽니다.
  3. Style Studio 아이콘을 Applications 폴더로 드래그합니다.
  4. 처음 실행 시 "확인되지 않은 개발자" 경고가 표시되면:
    • 시스템 설정 → 개인정보 보호 및 보안으로 이동
    • "확인 없이 열기" 클릭

Windows

  1. .exe 또는 .msi 파일을 다운로드합니다.
  2. 다운로드된 설치 파일을 실행합니다.
  3. SmartScreen 경고가 표시되면:
    • "추가 정보" 클릭
    • "실행" 클릭
  4. 설치 마법사의 안내에 따라 설치를 완료합니다.

시작하기

  1. Gemini API Key 발급

    Google AI Studio 에서 무료로 API Key를 발급받습니다.

  2. 앱 설정

    앱 실행 후 설정(⚙️)에서 API Key를 입력합니다.

  3. 이미지 분석

    새 세션을 만들고 참조 이미지를 업로드하면 AI가 스타일을 분석합니다.

  4. 이미지 생성

    분석 결과를 기반으로 새로운 이미지를 생성합니다.
